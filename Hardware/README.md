# 硬件设计说明

硬件系统主要由电源模块、主控模块、栅极驱动模块、功率逆变桥和反电动势（BEMF）检测模块组成。

## 模块详解

### 1. 电源模块

为了给整个系统提供稳定可靠的电源，设计了两级降压电路。

-   **第一级 (12V -> 5V)**:
    -   **核心芯片**: `TPS54202DDCR` (U1)
    -   **功能**: 采用 Buck 拓扑结构，将输入的 `12V` 电压高效地降至 `5V`，为比较器和后续的LDO供电。
    -   **保护**: 在 `12V` 输入端加入了 `SMBJ15A` TVS二极管 (D10)，用于吸收浪涌电压，保护后级电路。

-   **第二级 (5V -> 3.3V)**:
    -   **核心芯片**: `XC6206P332MR-G` (U10)
    -   **功能**: 采用 LDO (低压差线性稳压器)，将 `5V` 电压转换为 `3.3V`，专门为主控制器 `STM32` 供电，以确保其工作电压的稳定和纯净。

### 2. 主控模块

-   **核心芯片**: `STM32F103C8T6` (U4)
-   **功能**: 作为整个电调的大脑，负责：
    -   生成三路互补的 `PWM` 信号，用于控制栅极驱动器。
    -   接收来自比较器的 BEMF 过零信号，判断转子位置。
    -   执行开环启动、闭环控制、速度计算、堵转保护等核心算法。
-   **时钟**: 外部 `8MHz` 无源晶振 (X1) 提供主时钟源，倍频至 `72MHz` 运行。
-   **调试接口**: 板载 `SWD` 接口，用于程序的烧录和在线调试。

### 3. 栅极驱动模块

-   **核心芯片**: `EG2134` (U3)
-   **功能**: 高性能的三相半桥栅极驱动器。它接收来自 `STM32` 的 `3.3V` 逻辑电平信号，并将其转换为具有足够驱动能力的 `12V` 电压信号，用于快速、可靠地开关功率MOSFET。
-   **自举电路**: 通过自举二极管 (`D1`, `D2`, `D3`) 和自举电容 (`C3`, `C8`, `C11`)，为上桥臂 N-MOSFET 提供悬浮的栅极驱动电压。

### 4. 功率逆变桥

-   **核心器件**: `FH3040G8` (Q1-Q6) N-Channel MOSFET
-   **功能**: 由六个MOSFET组成标准的三相全桥逆变电路。它根据栅极驱动信号，将 `12V` 直流电逆变为三相交流电，驱动无刷电机转动。
-   **栅极电阻**: 每个MOSFET的栅极都串联了一个 `10Ω` 的电阻，用于抑制开关过程中的振荡，增强系统稳定性。

### 5. BEMF 反电动势检测模块

这是实现无传感器控制的关键部分，用于在电机运行时检测转子位置。

-   **虚拟中性点**: 通过三个 `4.7kΩ` 电阻 (`R8`, `R12`, `R14`) 将电机三相输出连接在一起，形成一个虚拟中性点 `MID`。理论上，在理想情况下此点的电位是三相电压的平均值。
-   **核心芯片**: `LM339ADT` (U5) 四路比较器
-   **工作原理**:
    1.  将虚拟中性点 `MID` 的电压作为基准电压，连接到三个比较器的同相输入端 (`IN-`)。
    2.  将经过 `4.7kΩ` 电阻 (`R8`, `R12`, `R14`) 简单分压后的三相端电压 (`UU`, `VV`, `WW`) 分别送入三个比较器的反相输入端 (`IN+`)。
    3.  当某一相的 BEMF 发生过零时，其端电压与虚拟中性点的电压关系会发生反转，导致对应比较器的输出状态翻转。
    4.  `STM32` 通过捕获这个翻转信号，即可精确得知 BEMF 的过零时刻。
-   **输出**: 比较器输出为开集电极，因此通过 `10kΩ` 上拉电阻 (`R5`, `R6`, `R7`) 将输出电平上拉至 `3.3V`，以匹配 `STM32` 的IO电平。
-   **设计注意**: 原理图上为 BEMF 信号预留了 RC 滤波电路 (`C13-C15`, `R9,R13,R15`) 的位置。

## MCU 引脚分配

| MCU 引脚 | 功能             | 连接至     | 备注                       |
| :------- | :--------------- | :--------- | :------------------------- |
| `PA8`    | HIN_U (PWM)      | `EG2134`   | U 相上桥臂 PWM 输出        |
| `PA9`    | HIN_V (PWM)      | `EG2134`   | V 相上桥臂 PWM 输出        |
| `PA10`   | HIN_W (PWM)      | `EG2134`   | W 相上桥臂 PWM 输出        |
| `PB12`   | LIN_U (PWM)      | `EG2134`   | U 相下桥臂 PWM 输出        |
| `PB13`   | LIN_V (PWM)      | `EG2134`   | V 相下桥臂 PWM 输出        |
| `PB14`   | LIN_W (PWM)      | `EG2134`   | W 相下桥臂 PWM 输出        |
| `PA0`    | UOUT (BEMF)      | `LM339`    | U 相 BEMF 过零检测输入     |
| `PA1`    | VOUT (BEMF)      | `LM339`    | V 相 BEMF 过零检测输入     |
| `PA2`    | WOUT (BEMF)      | `LM339`    | W 相 BEMF 过零检测输入     |
| `PA11`   | SWDIO            | SWD 接口   | 调试数据线                 |
| `PA12`   | SWCLK            | SWD 接口   | 调试时钟线                 |
